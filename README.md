## ⚙️ Principais Funcionalidades

- **Coleta de dados ambientais:** Leitura de sensores para monitorar condições como temperatura, umidade e luminosidade.
- **Visualização de status:** Utilização de LEDs para fornecer feedback visual sobre o estado do sistema (ex: ligado, coletando dados, alerta).
- **Comunicação de dados:** Envio dos dados coletados via porta serial para um computador para análise ou visualização.

## ▶️ Como Executar o Projeto

**Pré-requisitos:**
- [Arduino IDE](https://www.arduino.cc/en/software) instalada.
- Placa de Arduino (ex: Uno, Nano, etc.).
- [Componentes eletrônicos listados acima].

**Passo a passo:**

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/](https://github.com/seu-usuario/)[nome-do-repositorio].git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd [nome-do-repositorio]
   ```

3. **Abra o código na IDE do Arduino:**
   - Abra a Arduino IDE e vá em `Arquivo > Abrir...`.
   - Navegue até a pasta do projeto e abra o arquivo principal com a extensão `.ino`.

4. **Configure a IDE:**
   - No menu `Ferramentas > Placa`, selecione o modelo da sua placa Arduino.
   - No menu `Ferramentas > Porta`, selecione a porta COM em que o Arduino está conectado.

5. **Carregue o código:**
   - Clique no botão **Carregar** (seta para a direita) para compilar e enviar o código para a sua placa Arduino.
